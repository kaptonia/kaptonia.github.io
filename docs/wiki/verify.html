核验

收到授权或记录包，在左栏「核验」里自己核对。核验只读取公开的链和对方交来的文件，免费，记录者与使用方都能用。

核验授权

  1. 打开「核验 › 核验授权」。
  2. 贴入授权码，或按「选择文件…」选对方发来的授权文件。
  3. 收到了作品文件和条款文件的，也一起放进「文件」和「条款」两格。
  4. 按「核验」。

应用逐项检查六件事，每项一盏灯：

授权签名
确由签发者的密钥签署。
签发者账本完整
签发者的账本环环相扣。
在签发者账本里
这份授权确是那本账里的一条。
上链已确认
它已经上链。
在有效期内
此刻落在授权写明的期限之内。
未被撤销
读完签发者的整本账，这份授权依然有效。

结果是三种之一：

结果怎么办
六项全部通过可以放心用。放了文件和条款的，再看它们是否「相符」
有缺项有的项还在等结果，灰灯旁写着原因。过几分钟再核一次，或请对方补齐材料
未通过查出了问题，暂缓使用，与对方核实

只有授权码时，能核对签名和有效期；要完整核验，请对方发授权文件。

核验记录包

打开「核验 › 核验记录」，把记录包文件夹拖进去，放进去即开始核验。结论是两种之一：

  • 全部相符：记录包完整，签名有效，每件记录都已上链。包里带了哪些原件、是否相符，看下面「逐条记录」的「包内原件」一列。
  • 有 N 处不符：有地方对不上，请与对方核实后再接收。

「逐条记录」表每件记录一行，写着是否已上链和最早上链的时间。

对方用的是别的链

记录包写明了它锚在哪条链。那条链还没加进你的设置时，页上会出现提示，按「添加」，到「设置 › 网络」补上节点即可。核验会读你的主网络，加上「只读网络」里的每一条链。

查看他人账本

「核验 › 查看他人账本」：填对方的「作者地址」，按「读取」，就能看到对方上链过的记录和签发过的授权。
