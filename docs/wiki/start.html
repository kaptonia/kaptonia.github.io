上手

安装

到下载页下载你那个系统的安装包，每个系统的安装步骤都写在那里。

  • Mac：第一次打开前，要先在「终端」里去掉下载时带上的隔离标记，下载页有可以照抄的命令。
  • Windows：第一次打开时出现「Windows 已保护你的电脑」，按「更多信息」，再按「仍要运行」。Windows 11 开着「智能应用控制」时，先照下载页把它关掉。
  • Linux：用 .deb 安装，或给 AppImage 加上可执行权限后直接运行。

从早先版本升级时，先照下面的从早先版本升级把账本带过来。

通过 AI Agent 使用

有云端电脑的 AI Agent，可以自己把 ZIKARON 装好并进入可用状态，你只需要与它简单对话就可以使用；你电脑上的 AI Agent 会带你装好客户端，打开一次之后不必再开。两种情形各有一份提示词，在使用页，一键复制。各种用法的细节见命令行与AI 代理与远程操作。

从早先版本升级

这一版只读它自己写的加密形式，从一个空的机器目录起步；早先版本留下的密钥库、身份、设置和数据原样留在原处。记录者的账本照下面五步带过来：

  1. 在 0.1.2 里打开「设置 › 本机数据」，按「导出账本镜像」，存到机器目录之外的一个文件夹，然后退出。
  2. 把早先版本的机器目录连同它的指针文件挪到别处。Mac 与 Linux 上，指针文件是主目录里的 .zikaron-desk，机器目录默认是 .zikaron-desk.d；Windows 上两样都在 %LOCALAPPDATA%\ZIKARON\ 里。
  3. 打开新版，设口令，在「创建身份」一步按「导入已有密钥」，用同一组助记词导入。
  4. 到「创建账本」一步，点「收编已有账本目录」，选镜像里 ZIKARON-backup/<地址>/author 那个文件夹，按「原位收编」。条目逐条重新核验，再与链上的上链记录核对，这一步即算完成。
  5. 到「账本」页跑一趟账本检查，看它写「正常」。

别的身份照样：从身份牌的「导入密钥」导入，再在「设置 › 本机数据」「高级选项」里用「收编已有账本目录」收它的镜像。收到的授权在「我的授权」里重新添加，网络等设置重新设一遍。升级之后，请一直用新版打开这份数据：新版写的文件，早先版本读不了。

第一次打开

应用会弹出一个向导，左边六步，一步一步做：

  1. 设置口令。8 位字母或数字，以后每次打开应用都要输入。
  2. 创建身份。应用生成 12 个助记词，抄在纸上，再按提示填回其中三个。已有密钥的，也可以导入，或从整机备份恢复。
  3. 网络。选「以太坊主网」即可，应用自带公共节点。想先免费试一试，选「自定义」，再到「设置 › 网络」按「编辑节点」，在「预设」里选「Sepolia 测试网」，按「保存节点」和「保存链设置」。
  4. 创建账本。写一句说明（可以空着），按「创建账本」。免费。已有一本账（账本文件夹，或「导出账本镜像」写出的镜像）时，点旁边的「收编已有账本目录」，在「账本文件夹」里选它，按「原位收编」。
  5. 充值 gas。往页面上的地址转一点 ETH，或用钱包扫页面上的付款二维码（它写明所选的网络），按「我已转账」。可以「以后再说」。
  6. 整机备份。导出一个带密码的备份文件。可以以后再做，越早越好。

左栏左下角的「中文」|「English」从第一步起就能切换语言。「上一步」回到前一页；在核对助记词那一页按它，回到同一组十二个词。设好口令和身份之后，左下角有「退出向导」（Esc 同）。

助记词抄在纸上，放在只有你拿得到的地方。它能找回你的密钥；账本和设置靠整机备份找回。

第一条记录

左栏顶上选「记录者」。

  1. 存证。把文件拖进首页，写「记录名称」，按「加入账本」，在确认卡上再按一次。
  2. 上链。点首页的「待上链」卡，在弹出的「上链」卡上按「确认上链」。几分钟后，状态变成「已确认」。
  3. 授权。到「授权」按「新建授权」，填对方的地址，选这件记录，拖入条款文件，写进账本后同样上链。见授权。

原文件请自己保管好：日后举证，要拿出与记录一致的那一份。

收到别人的授权

  1. 左栏顶上切到「使用方」。
  2. 在首页「核验一份授权」里贴入对方发来的授权码，按「开始核验」。
  3. 到「我的授权」按「添加授权」，贴授权码或拖入授权文件，按「核验并添加」，收进库里。以后它快到期或被撤销，「提醒」页会告诉你。
