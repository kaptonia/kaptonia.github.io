存证与上链

账本是你自己的一本记录簿：一条接一条往后写，写下的每一条都原样保留。存证把一份文件记进账本，上链让任何人都能核对它的时间。

存证

  1. 把文件拖进首页或「记录存证」页，打开「新建存证」卡。文件夹和 Git 仓库也可以。
  2. 写「记录名称」；空着时自动填上文件的全名，扩展名照留。
  3. 按卡上的「加入账本」，记录即写进账本、排进待上链。

应用记下的是这份文件的内容指纹：同一份文件，算出的指纹永远相同；改动一个字节，指纹就全然不同。文件本身留在原处，应用只记下它的指纹。要一次记几份文件，在「新建存证」卡开着时把它们一起拖到卡上，每份各记一条。文件夹在哪个系统上都算出同一个指纹。

  • 原文件请自己保管好。日后举证，要拿出与指纹一致的那一份。
  • 记录名称和注记会随账本交给别人看，写下之后一直保留。
  • 很短、容易猜的内容（一个日期、一个金额），先和一段随机文字合成一个文件再存证。

上链

上链把账本里的新记录发进一笔交易，写进区块链。此后，任何人都能核对这些记录最迟在那一刻已经存在。

  1. 新记录先进「待上链」。点首页的「待上链」卡，直接打开「上链」卡；或在「记录存证」页的「待上链」里按「全部上链」。
  2. 卡上写着这一批的条数、Gas 费估算和 Gas 费上限。
  3. 按「确认上链」。几分钟后，状态变成「已确认」。

一批记录装在同一笔交易里，只付一笔的费用，所以攒几条一起发更省。可以关掉应用，下次打开会接着等结果。待上链跟着账本与链走：链上已有的条目移出队列、记为已上链；账本里链上还没有的条目（例如收编进来的），在下一趟账本检查之后排进队列。

  • 余额不够时，页顶的提示写着需要多少、现有多少，按提示上的「复制地址」去转一点 ETH。
  • 一批迟迟不入块时，「账本」页顶上账本状态卡的「上一批」一行出现「加价重发」，按它以更高的费用重发；同一批只付一次费。
  • 这一批里有存证已在链上时（例如命令行已把它送上链），应用一笔不发，提示「这一批里有存证已在链上，这一次一笔也没有发。」；等账本检查把那几条移出待上链，再发其余的。
  • 想每次写完就上链，打开「设置 › 网络」的「自动上链」。

上链越勤，时间越精确：每天上链一次，记录的时间就精确到一天。

状态

状态意思
待上链在队里，等你发出
正在等待上链已发出，等它进入区块
确认中已进入区块，等应用核对
已确认应用对着链核对过，完成
已回滚、未发出这一次没成，记录还在队里，可以再发

「账本」页顶上的账本状态卡写「正常」或「异常」。应用每隔几分钟把账本和链对一遍；写「异常」时，点开卡上的「账本检查」看是哪一项。「账本」页的「未确认」列出链上还没确认的每一条；还没有账本时，表下有蓝色的「创建账本」。

写错了怎么办

账本只往后添。已经写下的记录，用下面两种办法处理：

  • 补充说明：「账本」页「更多」里的「添加注记」，给那一条加一段说明。
  • 删除存证：在记录详情底部按「删除存证」。这件记录划掉显示，从可授权的记录里撤下；原来那一条和已发出的授权照旧保留。

网络

每个身份用一个网络，它的记录都发到这条链上：

网络用途
以太坊主网默认，最通用
Arbitrum One、OP Mainnet费用通常只有主网的零头
Sepolia 测试网免费试用，用的是测试币

新建身份时在「网络」一格里选。应用自带公共节点；想用自己的节点，到「设置 › 网络」按「编辑节点」，在「编辑节点与链」里改好，按「保存」。核验别人锚在其他链上的记录，把那条链加进「设置 › 网络」的「只读网络」。

VPN 与代理。「设置 › 网络」的「代理」决定应用连节点时从哪里出去，这台电脑上所有身份共用：

跟随系统代理
默认。照系统的代理设置走：系统填了自动配置脚本（PAC）地址时照脚本走，再是系统里手填的代理。脚本要在 https 地址上或本机上；在别的机器上、走 http 的脚本，改填「自定义代理」，或让网管改用 https 地址。
关闭代理
一律直连。
自定义代理
选代理类型（HTTP、HTTPS、SOCKS5 或 SOCKS4），填「主机」「端口」；代理要验身时再填「用户名」和密码（SOCKS4 只有「用户 ID」），按「保存」。从代理软件抄来的整段地址可以直接粘进「主机」格，应用把它拆进各格。密码加密存在本机，保存后显示「已设密码」。

本机上的节点一律直连；用自定义代理时，私网、链路本地与 .local 的节点也直连。下面一行「此刻新连接：…」写着现在是直连，还是经哪个代理；改了设置，下一次连接就照新的走。

  • 全局模式、接管全部流量的 VPN：保持「跟随系统代理」即可。
  • 只设了系统代理的 VPN：用「跟随系统代理」。
  • 还是连不上节点：在 VPN 软件里找到它的代理地址（HTTP、HTTPS、SOCKS5 或 SOCKS4，带用户名与密码的也行），填进「自定义代理」。
  • 提示「连不上代理。」时，核对代理地址；提示「代理要用户名与密码。」或「代理不收所给的用户名与密码。」时，在「自定义代理」里填对用户名与密码。

命令行经桌面 App 操作，或经凭据上链、扫链、找加密接收方的公钥时，用的也是这里的设置；设为「跟随系统代理」时只照系统的代理设置。纯命令行的 --proxy system（默认）先照终端的 https_proxy、http_proxy、all_proxy 走（连同 no_proxy），这三项都没设才照系统的代理设置。
