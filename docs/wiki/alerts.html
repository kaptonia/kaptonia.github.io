提醒与设置

「提醒」页把需要你处理的事集中在一处；设置分七项，两种角色相同。

提醒页

左栏「提醒」，表中每行一件事：一盏灯、事项和现状。需要处理的行右端有「去…」，点这一行即转到该处理的页面，并打开相关的部分。其余的行写「无需处理」。左栏「提醒」旁的数字，数的是黄灯和红灯的行。

记录者使用方
待上链我的授权即将到期
队列积压授权被撤销
授权即将到期整机备份
整机备份账本移交
账本检查结论上游异常
  • 「整机备份」：首次导出之前为「还没有备份」；上次备份后又多了账本条目或收到的授权时，为「N 条未备份」。
  • 撤销监测的提醒排在表末，每件一行，只在发现的那一次运行里列出；被撤销的授权在「我的授权」里一直标着「已被撤销」。

怎样通知你

下列事项新出现时，窗口向系统请求一次注意（在 macOS 上，程序坞图标会跳动），并出一条以「提醒：」开头的提示：记录者的「授权即将到期」「整机备份」，以及账本检查结论为断链；使用方的「我的授权即将到期」（含已过期）「整机备份」「上游异常」，以及撤销监测。其余黄灯、红灯只在提醒页和左栏数字里显示。

同一件事只提醒一次。情况变了，例如期限变了、上游账本有了新条目，算新的一件，会再提醒。网络错误只在状态行显示「同步失败」。

同步与状态行

状态行依次显示最要紧的一种：「进行中：…」（点它回到发起任务的那一页）、「正在同步…」「同步失败」「上次同步 时：分」「尚未同步」。点状态行右端的同步图标，按当前角色在后台读链：两种角色都读一次签名密钥余额；记录者建过账本的，再跑一趟账本检查；使用方再复核一遍我的授权。

检查周期

「设置 › 通知」：记录者的「账本检查」周期出厂为 300 秒，使用方的「授权核验周期」出厂为 600 秒。按「更改周期…」填秒数保存；填 0 即停掉定时，账本变过或还没有结论时，账本检查照样立即跑一趟。

设置七项

项内容
语言和时间「中文」或「English」；时区「UTC」（默认）或「跟随系统」，窗口里所有时刻都按它显示
外观「浅色」（默认）、「深色」或「跟随系统」
身份密钥身份、口令与密钥备份，见身份与密钥
网络节点、登记合约、自动上链与发布地址，见网络
通知账本检查与授权核验的周期
本机数据加密、备份与数据目录，见本机数据与备份
关于版本、设置检查、重新运行向导与诊断信息

外观、自动锁定、语言、选定的网络与上次整机备份的记录存在这台机器上，对所有身份生效，口令门上也用；其余设置存在当前数据目录里。

「关于」页的「设置检查」逐项一盏灯，尚待完成的标「待设置」；页底「详细信息」里有「运行自检」，在后台自检一次。

快捷键

键作用
⌘1 至 ⌘6按顺序打开左栏各项
⌘[ / ⌘]后退、前进
⌘,设置
⌘L锁定

在 Linux 上用 Ctrl 代替 ⌘。口令门、向导或卡片开着时，快捷键暂停。

按钮的颜色

蓝键
这一屏的主要动作，一屏至多一个。
白键
其他动作。
白底红字键
打开确认卡，或进入下一步，本身只是前往。
红色实心键
按下即写入账本或发上链，只出现在最后一步的确认卡上。
