从安装到第一条存证上链，约需十分钟，其中一半用于抄写助记词。

安装

{{VER}} 提供三个系统的安装包，在下载页取得，每个系统的完整步骤也在那里。每个包都附带第三方组件许可，应用的「设置 › 关于」里也能看到。

macOS
Apple 芯片，macOS 11 或更新。.dmg 打开后把 ZIKARON.app 拖进「应用程序」，命令行在应用包内的 ZIKARON.app/Contents/MacOS/zikaron；.pkg 把应用装进 /Applications，把命令行装到 /usr/local/bin/zikaron。应用由 Kaptonia 的自签证书签名，在 Apple 公证之外发出：先核对 SHA-256，再在「终端」里去掉下载时带上的隔离标记，系统才肯打开。
Windows
x86_64 的 Windows 10 与 11。zip 包解压到任意文件夹，双击 zikaron-desk.exe 即开，命令行是同一文件夹里的 zikaron.exe，程序自带运行库。程序未签名：首次打开时提示「Windows 已保护你的电脑」，按「更多信息」，再按「仍要运行」。Windows 11 开着「智能应用控制」时，要先在「Windows 安全中心」里把它关掉。
Linux
x86_64，glibc 2.31 或更新（Ubuntu 20.04、Debian 11 起）。.deb 用 sudo apt install 安装，窗口程序是 zikaron-desk，命令行是 zikaron；AppImage 加上可执行权限即可运行，打开的是窗口程序。两个包都未签名。系统的选档框经由桌面门户，需装 xdg-desktop-portal 和一个后端（如 xdg-desktop-portal-gtk）。

在 Linux 与 Windows 上，既收文件也收文件夹的拖放区（如新建存证）点开的选档框只能选文件，文件夹请直接拖进来。别的架构或发行版，按从源码构建自己构建。

窗口程序只开窗口，带参数启动时只说明原因；要处理文件，打开窗口后把文件拖进去，命令行的事交给 zikaron。窗口开不了时（多半是显卡驱动缺少所需的 OpenGL，或在没有 3D 加速的虚拟机、远程桌面里运行），它同样说明原因。

首次启动

还没设口令、还没有签名密钥，或当前是记录者而账本还没创建时，打开应用即弹出向导，停在第一个没完成的步骤。左边竖列六步，右边是当前这一步；每一步是否完成，按实际状态判断。

  1. 设置口令。8 位字母或数字，区分大小写，输入两遍。过于简单的口令当场退回：八位全同，或纯数字成连号、像日期。口令排在建身份之前，因为密钥要放进由口令开启的密钥库；密钥只住在应用自己的密钥库里，系统钥匙串一概不用。
  2. 创建身份。三选一：生成 12 个助记词，抄在纸上，再填回随机抽的三个词；导入已有密钥；从整机备份恢复。这台机器上建成的第一个身份就是主身份。在这里导入私钥时，同一张单上一并导出它的密钥文件，日后忘了口令，凭这份文件找回。
  3. 网络。「以太坊主网」带「推荐」标记，这台机器还没选过网络时默认选中它；另一项是「自定义」，到「设置 › 网络」自己填，或选一个预设。这里选的是第 2 步那个身份的网络，它的记录者与使用方两种角色同用。Sepolia 测试网、Arbitrum One、OP Mainnet 要用时选「自定义」，再在「设置 › 网络」的「预设」里选。在主网和两条二层网络上锚定，都要花真实的 ETH 付 gas。
  4. 创建账本。写一句账本说明（可留空），按「创建账本」，在确认卡上再按一次。这一步免费，只写入本地。导入的身份要等第 3 步之后与链上核对过，才能创建账本。
  5. 充值 gas。页面显示密钥地址和付款二维码。从你的钱包转入少量 ETH，按「我已转账」；向导读一次链上余额，大于零即完成。读余额需要节点，第 3 步选了「自定义」的，先配好节点。可以「以后再说」。
  6. 整机备份。导出一个带密码的备份文件，一个文件恢复全部。可以「以后再做」，宜尽早完成。

竖列底部的「退出向导」或 Esc 回到打开向导之前的页面，做完的步骤照旧算完；新生成而还没核对的助记词，退出即作废。真正的首次运行（打开时既没有口令也没有身份）这一轮没有退出口。其余步骤，可从「设置 › 关于」的「重新运行向导」接着做。

助记词抄在纸上，存放在只有你能取到的地方。助记词找回的是密钥；本机的账本、收到的授权与设置，靠整机备份找回；原文件请自己保留。

记录者的一条完整走法

左栏顶上选「记录者」。

  1. 存证。把作品文件拖进首页的拖放区，写「记录名称」，按「加入账本」，在确认卡上再按「加入账本」。
  2. 上链。点首页的「待上链」卡，或到「记录存证」的「待上链」分段按「全部上链」，在「上链」卡上按「确认上链」。几分钟后状态变为「已确认」。
  3. 授权。到「授权」按「新建授权」：填被授权方地址，按「选择记录」选一件已上链的记录，拖入条款文件，选有效期，按「加入账本」并在确认卡上再按一次，再像第 2 步一样上链。
  4. 交付。在授权详情里按「复制授权码」，或「导出授权文件…」，发给对方。授权文件带着你的账本，对方能做完整核验。
  5. 日常。看「提醒」页；需要时在授权详情里按「撤销授权…」。

存证一经写入即成定稿，需要补充时追加注记。原文件请妥善保管：日后举证，要出示与指纹逐字节一致的原件。

使用方的一条完整走法

  1. 第一次打开应用时，向导按记录者走：设口令、建身份、选网络、创建账本（免费，只写本地），其余可以以后再做。
  2. 在左栏顶上切到「使用方」。使用方的账本只在转授权时才需要，到时在转授权页按「开账…」即可。
  3. 在首页「核验一份授权」卡里贴入对方发来的授权码，按「开始核验」，看结果。
  4. 到「我的授权」按「添加授权」，贴授权码或拖入授权文件，按「核验并添加」，把它收进库里。
  5. 收到作品文件后，到「核验 › 核验授权」，把授权、文件和条款文件一起放进去，按一次「核验」，三件一起核对。
  6. 看「提醒」页：授权快到期、被撤销、签发者账本被移交，都会在这里出现。

窗口

左边是左栏，右边是页面。左栏从上到下：身份牌（当前身份的名字与种类，点开是带搜索格的身份菜单，可切换、新建或导入身份）、角色切换「记录者」|「使用方」、这一种角色的页面列表，底部是「设置」「锁定」和状态行。状态行右端的小图标是「同步」，点它在后台读一次链。

列表页顶上有一格搜索；记录存证、账本、授权、我的授权四页另有「开始日期」「结束日期」两格，点开是一张月历，设了日期，列表只留上链区块时刻落在这两天之间的行。要从清单里挑一项的地方（选择记录、最近地址、地址簿、注记的目标条目、切换身份），点开都是一张带搜索格的浮卡。

凡是写入账本或上链的动作，都先出一张确认卡，逐行写出要写什么、写到哪里、费用多少；在卡上按红色实心键才真正写入，按「取消」或 Esc 即作罢。耗时的动作（估算 Gas 费、上链、算指纹、迁移数据目录）都在后台做，按钮里显示进度，窗口照常可用。快捷键与其余设置见提醒与设置。
