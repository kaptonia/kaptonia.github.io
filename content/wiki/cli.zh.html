应用随附命令行 zikaron：一个操作一个子命令，每条命令在标准输出给一个 JSON 值，结论看退出码。它有两种用法：与桌面并行，或者单独使用。

接进终端

在「设置 › 本机数据」打开「启用命令行」，之后在终端里直接敲 zikaron 就能用。用 .pkg 或 .deb 安装的，装完就已经可以；用 AppImage 的，要用命令行请装 .deb。Windows 上的 zikaron.exe 要在终端里运行。

运行 zikaron contract，列出全部子命令、各自的参数和退出码。每条命令的写法见开发者指南 · 命令行。

用法一：与桌面并行

桌面开着并已解锁时，命令带上数据目录 --home "<数据目录>"，就交给正在运行的 ZIKARON Desk 去做。桌面用你的身份签名，写进它的账本，走的是与你亲手点按同一条路：同样的检查，同样的提示，窗口里随即更新。私钥和口令一直留在桌面里，命令行只递请求。

  • 数据目录在哪：「设置 › 本机数据」的「详细信息」里，「数据目录」一行就是当前身份这一角色的数据目录路径。
  • 只读的事：核验别人的材料这类只读的操作，命令行直接就能做。
  • 桌面上做的事：设口令、管理密钥、整机备份，以及要输口令的操作，在桌面上做。
  • 通道何时开着：本机通道只对这台电脑上的你开放，只在桌面解锁、开着这个数据目录时开着；锁定、关闭数据目录或退出，通道即关，命令行收到退出码 4。

上链的两种模式。命令行让桌面上链时，按「设置 › 网络」的「命令行上链」走：

自动发送
默认。桌面照「全部上链」的做法，把队里能发的条目一次发出，费用从这个身份的地址里付。30 秒内进入区块，命令行交回区块号和交易号；还在等时，命令行先答交易还没入块(退出码 4)，桌面接着等收据。
仅加入队列
桌面把条目留在队里，命令行答「已在队列,待用户在桌面上发」(退出码 3)。桌面弹出提示「命令行提交了 N 条记录,已加入队列」并提醒你一次，你在桌面上核对后按「确认上链」。

用法二：纯命令行

命令行自己就能从头做起，用不着桌面，也用不着图形界面：

  1. 生成密钥。在你自己的终端里运行 zikaron keygen，它输出一个新地址和它的私钥。把私钥那一串存进一个文件，设成只有你能读(macOS 与 Linux 上用 chmod 600)，之后的命令用 --key-file 指向它。
  2. 充值 gas。往这个地址转一点 ETH。
  3. 建账本。zikaron init --ledger "<账本目录>" --key-file "<私钥文件>" --statement "<说明>"。之后存证、授权、撤销、注记等写入，都带这两项写进这个账本目录。
  4. 上链。anchor 用 --endpoint 指定节点，--registry 指定登记合约(以太坊主网上是 {{MAINNET}})，--hash 给要上链的条目编号，可以给好几个，一笔交易锚多条。同一条命令重跑时，先查已经签过的交易，同一次上链只付一次费。
  5. 核验与出示。用 scan 和 audit 对着链检查账本，用 kit-export 导出记录包，用 check-grant 核验授权。

写出的账本与桌面写的是同一种格式，任何人用桌面应用或命令行都能核验。日后要把这本账接进桌面，先用「导入密钥…」导入这把私钥，再在「设置 › 本机数据」的「高级选项」里用「原位收编」。

明文的文件

纯命令行时，下面几样以明文存在磁盘上：

文件里面是什么
私钥文件这把密钥本身。拿到它，就能以你的身份签任何条目，也能花掉地址里的 ETH
账本目录每条条目，内容本来就要交给别人核验；条目改一个字节，签名就对不上
cli-sent/命令行签过的交易哈希

要紧的是私钥文件。能用这个系统账户读文件的人或程序，都能读到它，所以这样保管：

  • 只放小钱、只管专用的账。这把钥单独用，地址里只放够付 gas 的 ETH，与你主要的身份分开。
  • 守住系统账户。开启系统的全盘加密；远程登录只许用密钥。
  • 私钥只经文件交给命令行。用 --key-file 给，命令行只认只有你能读的私钥文件；文件放在同步盘与自动备份的文件夹之外，另抄一份放在离线的安全处。
  • 能走桌面就走桌面。与桌面并行时，私钥在桌面的密钥库里，用口令加密。纯命令行留给真正需要无界面的场合。

两种用法怎么选

与桌面并行纯命令行
私钥在桌面的密钥库里，口令加密，有助记词与整机备份一个明文文件，只靠文件权限保护；备份是另存的一份
图形界面要，桌面开着并已解锁用不着
上链桌面的队列、估费、多节点交叉核对自己指定节点和要上链的条目，一次问一个节点
检查与提醒桌面定期自动做，有「提醒」页自己运行 scan 与 audit
交出授权授权文件、授权码、凭证授权码与凭证，或记录包
适合在你自己的电脑上日常使用一把专用的钥、无界面的主机、成批的自动化

命令行的答复

退出码意思
0完成，或核验通过
1被拒，或核验未通过；原因在输出里
2命令写错了，标准输出为空
3部分结果(例如有的项还在等结果)，或已加入队列，等你在桌面上发
4没有答案：桌面没有作答(已退出、已锁定，或开着别的数据目录)、连不上节点，或交易还没入块
