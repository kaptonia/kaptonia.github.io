ZIKARON quick start (for an AI agent)
1. Fetch and install: download the latest package from the Releases of https://github.com/kaptonia/zikaron, check it against SHA256SUMS.txt, then install. On Linux: sudo DEBIAN_FRONTEND=noninteractive apt-get install -y -o Dpkg::Options::=--force-confold ./zikaron-desk_*_amd64.deb
2. Read: README.md (networks and contract addresses) and CLI-SCHEMA.md (how to use each command). Once installed, run zikaron contract and go by the subcommands, flags and exit codes it lists.
3. Get to work:
   - If the user already runs ZIKARON Desk on their own computer, prefer --home or "With a credential", so the private key stays on the user's computer.
   - Otherwise: generate a key with zikaron keygen, save it in a file with mode 600 and keep it out of sight; ask the user whether they want a copy of the key file to keep; if so, hand it over as a file, never pasted into the chat, and remind them to store it offline; then create a ledger with zikaron init; ask the user to send a little ETH to the address for gas.
4. Every day: record with history --file → put on chain with anchor → check with scan, then audit; to share, export a record kit with kit-export, which the other side checks with kit-verify. Gather several records and put them on chain together, paying gas for one transaction.
5. Upgrading: check Releases regularly. For a new version, first read the release notes and the upgrading part of CHANGELOG, check the package against SHA256SUMS.txt, then install it over the old one as in step 1. Command-line ledger folders keep working across versions. If the release notes call for a migration by hand, tell the user first and go ahead once they agree. After upgrading, run zikaron contract to see whether any command changed. At every upgrade, remind the user to download a ledger backup (pack the ledger folder into one file and hand it over), and agree with them on regular backups from then on.
6. When the user wants the safer desktop app, walk them through it step by step:
   - Open the download page https://kaptonia.github.io/en/use.html, download for the user's system, check the SHA-256, then install. On a Mac, the quarantine mark comes off before the first launch; the download page has the command to copy.
   - First launch: set a passcode and write the recovery words on paper, kept somewhere offline. The recovery words stay with the user alone; ask them to keep the words to themselves.
   - Bring the ledger into the desktop, one of two ways:
     · Hand the private key to the user, who imports it with "Import key" in the desktop app and takes the ledger in with "Adopt existing ledger folder". After adoption, the desktop writes the original folder's ledger.
     · Write the ledger into a handoff file with hand-over and give it to the user, who takes it on the desktop side with take-over; from then on the ledger is written by turns in the two places.
   - Then ask the user to turn on "Through the desktop app" or "With a credential" in Settings › Command line; switch to --home or the credential, and delete the private key file in the cloud afterwards.
7. Rules: the private key and the recovery words stay out of chats and logs; one place writes a ledger at a time, and to move the writing use hand-over / take-over.
