Install

  1. Check the SHA-256; it should match the value listed under Check below:
    shasum -a 256 ~/Downloads/ZIKARON-0.1.2-macos-arm64.dmg
  2. In Terminal, remove the quarantine flag macOS adds to downloads:
    xattr -d com.apple.quarantine ~/Downloads/ZIKARON-0.1.2-macos-arm64.dmg

    Do this before you open the dmg.

  3. Open the dmg, drag ZIKARON.app to Applications, then open it.

    If you dragged the app in first, run this instead:

    xattr -dr com.apple.quarantine /Applications/ZIKARON.app

    The zikaron command line is inside the app bundle: ZIKARON.app/Contents/MacOS/zikaron. To type zikaron in any terminal, turn on “Enable command line” in the app’s Settings › Local data: it places a link in /usr/local/bin, and macOS asks for an administrator password when needed.

  1. Check the SHA-256; it should match the value listed under Check below:
    shasum -a 256 ~/Downloads/ZIKARON-0.1.2-macos-arm64.pkg
  2. In Terminal, remove the quarantine flag macOS adds to downloads:
    xattr -d com.apple.quarantine ~/Downloads/ZIKARON-0.1.2-macos-arm64.pkg

    Do this before you double-click it.

  3. Double-click the pkg to install.

    The installer puts the app in /Applications and the command line at /usr/local/bin/zikaron, so zikaron works in a terminal right after installing.

Change the paths to wherever you downloaded the files.

Why this step: the app is signed with Kaptonia’s self-signed certificate and is outside Apple’s notarization. Files downloaded in a browser carry macOS’s quarantine flag, and macOS refuses to open them; on recent macOS, Open Anyway in System Settings › Privacy & Security works only some of the time. Checking the file and then removing the flag tells the system you trust the file you have checked.

To upgrade, install the new version over the old one; your ledgers and local data open as before. Encrypted local files a new version writes are read by the new version, so after upgrading, keep opening the same data with the new version.

  1. In PowerShell, check the SHA-256; it should match the value listed under Check below:
    Get-FileHash ~\Downloads\ZIKARON-0.1.2-windows-x86_64.zip -Algorithm SHA256

    PowerShell prints the value in capitals; compare it without regard to case.

  2. Unzip it to any folder and double-click zikaron-desk.exe.

    There is nothing to install, and the runtime comes with the program. The command line is zikaron.exe in the same folder and runs in a terminal: hold Shift, right-click an empty spot in the folder, choose “Open in Terminal” (“Open PowerShell window here” on Windows 10), then type .\zikaron.exe with a verb and its flags. Double-clicked in Explorer, it only flashes a window.

  3. If the first launch shows “Windows protected your PC”, click More info, then Run anyway.

Change the paths to wherever you downloaded the files.

Why this step: the program is unsigned. On Windows 11 with Smart App Control on, unsigned programs are blocked outright, with no Run anyway and no way to allow this one program; to use it, first turn Smart App Control off under Windows Security › App & browser control › Smart App Control settings.

To upgrade, replace the old folder with the new one. Your local data lives in %LOCALAPPDATA%\ZIKARON\, so deleting the unzipped folder leaves it in place. Encrypted local files a new version writes are read by the new version, so after upgrading, keep opening the same data with the new version. Start menu entries and desktop shortcuts are up to you; to type zikaron in any terminal, turn on “Enable command line” in the app’s Settings › Local data, which adds the command line’s folder to this user’s PATH.

  1. Check the SHA-256; it should match the value listed under Check below:
    sha256sum ~/Downloads/zikaron-desk_0.1.2_amd64.deb
  2. Install it:
    sudo apt install ~/Downloads/zikaron-desk_0.1.2_amd64.deb

    For Debian, Ubuntu and their derivatives. The window program is zikaron-desk, also in the applications menu; the command line is zikaron; both go in /usr/bin, so zikaron works in a terminal right after installing.

  1. Check the SHA-256; it should match the value listed under Check below:
    sha256sum ~/Downloads/ZIKARON-0.1.2-x86_64.AppImage
  2. Make it executable, then run it:
    chmod +x ~/Downloads/ZIKARON-0.1.2-x86_64.AppImage ~/Downloads/ZIKARON-0.1.2-x86_64.AppImage

    There is nothing to install; it opens the window program. If the system lacks FUSE, add --appimage-extract-and-run to the command. The command line inside cannot be called directly; for the command line, install the .deb.

Change the paths to wherever you downloaded the files.

Neither package is signed; check them by their SHA-256. The system file dialog goes through the desktop portal, so install xdg-desktop-portal and a backend such as xdg-desktop-portal-gtk; without a portal, drag files straight into the window. Dropping files needs X11: with an X display (XWayland on a Wayland desktop included) it works as usual, and a pure Wayland session with no X display receives no dropped files.

To upgrade, install the new version; your ledgers and local data open as before. Encrypted local files a new version writes are read by the new version, so after upgrading, keep opening the same data with the new version.

Other architectures or distributions: build from source; see Developer guide · Building from source.
