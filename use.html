交给 AI Agent
ZIKARON 最简上手（给 AI agent） 1. 拉取并安装：从 https://github.com/kaptonia/zikaron 的 Releases 下载最新安装包，用 SHA256SUMS.txt 校验后安装。Linux 用：sudo DEBIAN_FRONTEND=noninteractive apt-get install -y -o Dpkg::Options::=--force-confold ./zikaron-desk_*_amd64.deb 2. 读说明：README.md（网络和合约地址）和 CLI-SCHEMA.md（命令用法）。装好后运行 zikaron contract，以它列出的子命令、参数和退出码为准。 3. 进入工作状态： - 用户本机已经有 ZIKARON 桌面版的话，优先用 --home 或「经凭据操作」，私钥留在用户电脑上。 - 否则：zikaron keygen 生成私钥，存进 600 权限的文件，绝不显示；问用户要不要把这个私钥文件交给他保管一份，要的话以文件交付，不贴进聊天，并提醒他存到离线的地方；然后 zikaron init 建账本；请用户往这个地址充一点 ETH 付 gas。 4. 日常：history --file 记录 → anchor 上链 → scan 后 audit 核验；要分享就 kit-export 导出记录包，对方用 kit-verify 核验。几条记录攒在一起上链，一笔交易只付一次 gas。 5. 升级：定期查看 Releases。有新版本时，先读发布说明和 CHANGELOG 里的「升级」一节，再用 SHA256SUMS.txt 校验，然后照第 1 步覆盖安装。命令行的账本目录跨版本照常读写。发布说明要求手工迁移的话，先告诉用户，得到同意再动手。升级后运行 zikaron contract，确认命令有没有变化。每次升级时提醒用户下载一份账本备份（把账本目录打包成一个文件交给用户），并和用户约好以后定期备份。 6. 用户想换用更安全的桌面版时，一步一步带用户做： - 打开下载页 https://kaptonia.github.io/use.html，按用户的系统下载，先核对 SHA-256 再安装。Mac 第一次打开前要去掉隔离标记，下载页有可以照抄的命令。 - 第一次打开：设口令，把助记词抄在纸上，放在离线的地方。助记词只由用户自己保管，不要让用户发给你。 - 把这本账带进桌面，二选一： · 把私钥交给用户，让用户在桌面版「导入密钥」，再用「收编已有账本目录」收进来。收编后，原目录由桌面接管。 · 用 hand-over 把账本写成交接件交给用户，用户在桌面一侧 take-over 收下，之后账本在两处之间轮流写。 - 之后请用户在「设置 › 命令行」打开「经桌面 App 操作」或「经凭据操作」，你改用 --home 或凭据工作，云端的私钥文件随后删掉。 7. 规矩：私钥和助记词不进聊天和日志；一本账同一时间只能有一处写，换地方写用 hand-over / take-over。

密钥与升级

  • AI Agent 在云端用一把专用的密钥写账本，地址里只放够付 gas 的少量 ETH。
  • 想让私钥留在自己电脑上，装上，再让 AI Agent 经「经凭据操作」或 --home 替你做。提示词第 6 条写了它怎样一步步带你换过去。
  • 新版本发布时，AI Agent 照提示词第 5 条自己校验并升级。

安装

  1. 核对 SHA-256，结果应与下方「核对」里列出的一致：
    shasum -a 256 ~/Downloads/ZIKARON-0.1.3-macos-arm64.dmg
  2. 在「终端」里去掉下载时系统加上的隔离标记：
    xattr -d com.apple.quarantine ~/Downloads/ZIKARON-0.1.3-macos-arm64.dmg

    这一步在打开 dmg 之前做。

  3. 打开 dmg，把 ZIKARON.app 拖进「应用程序」，再打开它。

    已经先拖进去了的，改为运行这一条：

    xattr -dr com.apple.quarantine /Applications/ZIKARON.app

    命令行 zikaron 在应用包内：ZIKARON.app/Contents/MacOS/zikaron。要在终端里直接敲 zikaron，打开应用「设置 › 命令行」的「启用 zikaron 命令」：它在 /usr/local/bin 放一个链接，需要时 macOS 弹出自己的管理员口令框。

  1. 核对 SHA-256，结果应与下方「核对」里列出的一致：
    shasum -a 256 ~/Downloads/ZIKARON-0.1.3-macos-arm64.pkg
  2. 在「终端」里去掉下载时系统加上的隔离标记：
    xattr -d com.apple.quarantine ~/Downloads/ZIKARON-0.1.3-macos-arm64.pkg

    这一步在双击安装之前做。

  3. 双击安装。

    安装程序把应用装进 /Applications，把命令行装到 /usr/local/bin/zikaron，装完即可在终端里敲 zikaron。

命令里的路径按你实际下载的位置改。

为什么有这一步：应用由 Kaptonia 的自签证书签名，在 Apple 公证之外发出。从浏览器下载的文件带着 macOS 的隔离标记，系统会拒绝打开；在较新的 macOS 上，「系统设置 › 隐私与安全性」里的「仍要打开」时常失灵。先核对文件，再去掉隔离标记，就是向系统确认你信任这份核对过的文件。

升级时，用新版覆盖安装即可。从 0.1.2 或更早的版本升级：本版从一个空的机器目录起步，早先版本的账本照下面几步带过来：先在旧版里「导出账本镜像」到机器目录之外的文件夹，然后退出；把旧的机器目录 ~/.zikaron-desk.d/ 连同指针文件 ~/.zikaron-desk 一起挪开；启动本版，设口令，用同一组助记词导入身份；向导走到「创建账本」时点「收编已有账本目录」，选镜像里的 author 文件夹，按「原位收编」；最后在账本页跑一趟账本检查，看它答「正常」。本版写过的本机加密文件，早先版本读不了。
